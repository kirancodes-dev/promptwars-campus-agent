# CampusPilot AI — frontend

React 19 + Vite 8 + Tailwind CSS 4 single-page app. See the root [README](../README.md) for setup.

- `npm run dev` — dev server on :5173, proxies `/api` to the backend (default `http://127.0.0.1:8000`)
- `npm test` — Vitest + Testing Library
- `npm run lint` — ESLint
- `npm run build` — production build into `dist/` (served by FastAPI)
